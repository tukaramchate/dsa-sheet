Which pattern should I use? (clue → pattern)
Sorted array, find pair / triplet / mergeTwo pointers
Longest / shortest / count subarray or substring with a conditionSliding window (or prefix sum + hashmap if negatives)
Sorted or monotonic answer space, "minimum max" / "maximum min"Binary search on answer
Next greater / smaller element, histogram, spanMonotonic stack
Cycle, middle, nth from end in linked listFast and slow pointers
Top K, K-th largest, running median, schedulingHeap / priority queue
All subsets, permutations, combinations, board placementBacktracking
Shortest path in unweighted graph or grid, level by levelBFS
Connected components, islands, cycle detection, tree problemsDFS
Dependencies, ordering, prerequisitesTopological sort
Merge groups, "are these connected" queriesUnion Find
Weighted shortest path / minimum spanning treeDijkstra, Bellman-Ford / Prim, Kruskal
Count ways, min/max cost, overlapping subproblemsDynamic programming (1D, grid, knapsack, LCS, LIS)
Locally optimal choice works, intervals, schedulingGreedy + sorting
Prefix lookup, autocomplete, word dictionaryTrie
Values in range 1..n, find missing / duplicateCyclic sort / index marking
XOR, powers of two, single element among pairsBit manipulation
